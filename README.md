# Proposition de site – Journées du Patrimoine de Rabat-Salé

Projet étudiant (Projet tutoré de conduite du changement, Projet D – EST Salé, 2026/2027).
Groupe : Samia Lamsakhar, Salma Machi, Yassir Ed-Dra – encadré par Pr. El Ouali.

Ce site est une **maquette pédagogique** qui illustre la digitalisation proposée
(réservation en ligne des groupes, espace bénévoles, tableau de bord).
Il n'est ni édité ni validé par l'Association Rabat-Salé Mémoire, et le formulaire
n'envoie aucune donnée.
